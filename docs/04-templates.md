# Templates

## Dashboard

Page header and global filters → primary metrics → main trend and supporting summary → distribution → recent records. Not every metric deserves equal visual weight.

## List page

Page header → search/filter toolbar → result summary and bulk actions → table/list → pagination → all system states.

## Detail page

Identity and status → primary actions → grouped attributes → activity/audit history. Keep dangerous actions separate.

## Form page

Purpose and scope → logical field sections → validation and dependencies → sticky or predictable save actions → result feedback.

## Mobile main flow

System app bar → task content → contextual action → native back behavior. Prefer bottom sheets for short contextual choices and full screens for focused multi-step work.
