# Platform mapping

| Semantic role | Portal | Android |
|---|---|---|
| Primary action | `palette.primary.main` | `brand_500` / theme primary attribute |
| Canvas | `background.default` | screen background theme attribute |
| Surface | `background.paper` | surface/container resource |
| Primary text | `text.primary` | `text_primary` / `text_primary_dark` |
| Secondary text | `text.secondary` | `text_secondary` / `text_secondary_dark` |
| Focus | focus-visible outline | accessibility focus/ripple state |
| Default radius | 8px | 8dp where the native component permits |
| Body type | 14px/22 | 15sp/20sp |

The Portal follows Mantis layout behavior. Android does not reproduce the web dashboard shell; it inherits only brand, semantic status, hierarchy, and calm visual character.
