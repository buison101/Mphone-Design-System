# Mphone Portal Workspace

## Projects

- `mpo-design`: current Portal UI built with React, Vite and MUI.
- `spa`: earlier Portal implementation retained as a reference.
- `service`: Portal service files.
- `resources`: shared Portal resources.

## MPO Design

Run commands from `mpo-design`:

```sh
npm run start
npm run prettier:check
npm run lint
npm run i18n:check
npm run build
```

The local preview is available at `http://127.0.0.1:4323/`.
